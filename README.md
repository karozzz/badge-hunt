# badge-hunt

Small repo for earning GitHub profile achievements.

## Targets

- Quickdraw
- YOLO
- Pull Shark
- Pair Extraordinaire

## How

- Quickdraw: close an issue within 5 minutes of opening it
- YOLO: merge a PR without review
- Pull Shark: 2 merged PRs
- Pair Extraordinaire: co-authored commit in a merged PR
